Современная высокопроизводительная платформа (аналог Flowwow), построенная на передовом стеке технологий. Проект реализован с соблюдением принципов чистой архитектуры и ориентирован на мобильных пользователей (PWA).

## 🚀 Технологический стек

- **Backend:** C# / .NET 10, ASP.NET Core Web API
- **Архитектура:** Clean Architecture (Onion), Modular Monolith
- **База данных:** PostgreSQL + EF Core (Code First), использование JSONB для динамических атрибутов
- **Логистика:** Расчет стоимости доставки по радиусам (формула Haversine), интеграция с DaData для автодополнения адресов
- **Frontend:** React + TypeScript + Vite + Ant Design
- **Управление данными:** Zustand (State Management) & TanStack Query v5
- **Инфраструктура:** Docker, Docker Compose, Nginx

## ✨ Ключевые возможности

- **Мульти-вендорность:** Полноценные кабинеты для продавцов (управление магазином, товарами и заказами).
- **Сплит-платежи:** Логика автоматического разделения оплаты между платформой (комиссия) и магазином.
- **Умная логистика:** Динамический расчет стоимости доставки на основе координат магазина и покупателя.
- **Система лояльности:** Автоматическое начисление бонусов (кэшбек) при завершении заказа.
- **PWA (Progressive Web App):** Возможность установки сайта как приложения на iOS и Android.
- **Автоматизация:** Фоновый сервис (Background Service) для контроля срока жизни товаров "Собран сегодня" (24ч).

## 🏗 Архитектура проекта
Проект разделен на логические слои:
- **Domain:** Ядро системы, сущности и бизнес-правила.
- **Application:** Интерфейсы, DTO, маппинг (AutoMapper) и бизнес-логика.
- **Infrastructure:** Реализация доступа к БД, файловое хранилище, интеграция с внешними API.
- **API:** Точка входа, контроллеры и конфигурация Scalar (OpenAPI).

## 🛠 Быстрый запуск

1. Склонируйте репозиторий.
2. Настройте переменные окружения в `docker-compose.yml` (JWT ключ, DB connection).
3. Запустите проект одной командой:
   ```bash
   docker-compose up -d --build
   ```
